# SimuS-jogo-da-velha

### Para jogar:

Abra o link (https://simulador-simus.github.io/apps/simus-web-v1.2.html)

Cole o Código da Branch Main.

### Controles:

Para jogar coloque o valor correspondente na entrada e remova +-2 segundos após:

8 -> cima

2 -> baixo

4 -> esquerda

6 -> direita

3 -> confirma a jogada
